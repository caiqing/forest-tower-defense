# 森林守望 · Forest Tower Defense

单文件 HTML5 森林主题塔防游戏。黑暗兽群沿小径逼近**森林之心**，布置防御塔守住 20 波进攻即可胜利，通关后可继续无尽模式。

## 运行

直接用浏览器打开 `index.html` 即可，无需构建、无外部依赖。

## 玩法

- 从底部卡片选择塔，点击草地建造；点击已建塔可**升级**（3 级）或**出售**（返还 70%）
- 点击「开始下一波」迎战，敌人沿小径进攻森林之心，漏怪扣生命（Boss 扣 5）
- 生命归零失败；守住第 20 波胜利，之后可进入**无尽模式**挑战纪录
- 最高波次纪录自动保存在浏览器本地
- **每日签到**：每天打开游戏可在顶栏领取 100 金币（顶栏按钮高亮提示）；忘记签到断签后，下次进入游戏按漏签天数每天扣 10 金币，连续签到天数会累计、断签后重置

## 防御塔

| 塔 | 花费 | 特点 |
|---|---|---|
| 🏹 弓箭哨塔 | 90 | 射速快、单体伤害，满级一次双箭 |
| 🍄 孢子菇 | 120 | 孢子抛射溅射伤害，克制成群敌人 |
| 🌿 荆棘丛 | 100 | 缠绕减速敌人，满级减速 62% |
| ⚡ 雷霆花 | 180 | 连锁闪电弹跳多个目标，威力最大 |

## 敌人

甲虫（基础）、野猪（快速）、灰狼（均衡）、赤鼠（高速）、独角仙（重甲坦克）、暗影巨鹿（Boss，每 5 波出现，终局双 Boss）。

## 操作

- 鼠标：选塔 / 建造 / 点塔升级出售
- 快捷键：`1-4` 选塔 · `Esc` 取消 · `N` 开始下一波 · `空格` 暂停
- 顶栏：×1/×2/×3 变速 · 音效开关 · 暂停；底部支持自动开波倒计时

## 技术

纯 Canvas 2D 手绘矢量画面（无图片素材），WebAudio 合成音效，粒子/飘字/震屏等游戏反馈，单文件约 1300 行，支持触屏（Pointer Events）。
